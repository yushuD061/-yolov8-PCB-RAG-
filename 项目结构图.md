## 关键契约

| 端 | 类型文件 | 内容 |
|---|---|---|
| 后端 | `backend/models.py` | SystemConfig / HardwareTelemetry / DetectionTarget / AlarmRecord |
| 后端 | `backend/schemas.py` | WSRequest / WSPushMessage / ProcessTask / LlmApiConfig |
| 后端 | `backend/agent/rag_engine.py` | RagChunk / RetrievalHit（dataclass 范式样板） |
| 后端 | `backend/store/base.py` | AlarmStats / DailyStat |
| 板端 | `scripts/board_config.py` | BoardConfig / Detection / Target |
| 前端 | `web2/src/types.ts` | SimulatedTarget / TelemetryMetrics / AlarmEvent / SystemConfig / WS* union / RAG* |

## 跨端协议要点

- 检测框坐标统一为 **0-100% 相对中心 + 宽高**（板端、后端、`/api/detect/image`、`dataAdapter` 一致）；
- WS 文本：`{type, data}`（推送）/ `{id, method, channel, data}`（请求）；二进制即 JPEG 视频帧；
- `localInference` 默认 false → 板端推流、PC 仅做转发与统计；置 true → PC 跑本地 YOLO 推理。
